Box Model Key Concepts

A reference guide to CSS spacing, borders, and sizing behaviors.

← Back to Visualizer
content-box (Standard Model)
The default browser behavior where width and height apply exclusively to the content area. Padding and border values are added on top, increasing the element's actual rendered size on the screen.
border-box (Alternative Model)
Activated by setting box-sizing: border-box. Declared width and height include the content, padding, and border. The inner content shrinks automatically as padding and borders expand.
Content Area
The innermost rectangular box where text, media, and nested elements are placed.
Padding
The space between the content area and the border. The element's background color or background image extends through this area. Negative padding is invalid in CSS.
Border
The visible or invisible line drawn between the padding and margin. Configured via shorthand (border) or individual properties for width, style, and color.
Margin
The outermost buffer zone that pushes neighboring elements away. Margins can accept negative values, which pull elements closer or cause them to overlap.
Margin Collapsing
When two vertical block margins touch, they combine into a single margin equal to the larger of the two values, rather than adding together.
